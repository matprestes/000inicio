# Phase 2: Sistema de Diseño y Marca

## Objetivo
Implementar la **Ley de Tres Colores** en Tailwind CSS v4, definir la tipografía especializada (Anton, Bebas Neue, Outfit, Geist Mono) y establecer los componentes con la firma geométrica de Doble Bisel y Botones Pill.

## Reglas Clave:
1. **Ley de Tres Colores:** Azul Canónico (`#0950F6`), Amarillo Vial (`#FFEC01`, máx 15% del área) y Blanco Puro (`#FFFFFF`). Prohibido negro puro (`#000000`) y grises genéricos.
2. **Tipografía:** Anton (display), Bebas Neue (eyebrows/subtítulos), Outfit (cuerpo), Geist Mono (métricas/precios).
3. **Componentes Clave:** `DoubleBezelCard` y `CTANestedPill`.

## Archivos en este directorio:
- `prompt.md`: Prompt maestro para la IA.
- `references/globals.css`: Estilos globales y tokens CSS personalizados con Tailwind v4.
